jspackr bundles one entry point and its imports for browser use. Choose an output format, optionally minify or emit a source map, and run a rebuild watcher from the same CLI.

## What jspackr does

jspackr invokes esbuild with bundling enabled and the browser platform. It accepts one entry point, follows its imports, and writes one output file. The default output format is `iife`; ESM and CommonJS are also available.

TypeScript and JSX syntax are transformed by esbuild when used in supported file extensions. Optional type checking runs the project's local TypeScript compiler with `--type-check`; esbuild remains responsible for bundling. See [TypeScript and JSX](/guides/typescript-jsx/) for details.

## Build pipeline

```text
optional tsc --noEmit → esbuild bundle → output file
```

There is no CLI support for multiple entry points, code splitting, plugins, or selecting a target environment. See [supported features](/reference/supported-features/) for the current scope.
